# MVP Plan

## Phase 1: Project Scaffolding

Success criteria:

- Next.js app runs locally with App Router.
- TypeScript, linting, unit tests, and Playwright are configured.
- `.gitignore` excludes local secrets, dependencies, build output, and test artifacts.

## Phase 2: Portfolio MVP

Success criteria:

- Home page presents Brandon Williams as a software engineer in Tokyo.
- Page includes an about section, career journey, skills, education, and contact links.
- Visual design is professional, responsive, and intentionally minimal.

## Phase 3: Verification

Success criteria:

- Unit tests cover the core profile content and rendered page landmarks.
- Playwright validates the live page loads, renders key content, and exposes working contact links.
- Lint, tests, and production build complete without defects.

## Phase 4: Handoff

Success criteria:

- Decision-making is recorded in `docs/DECISIONS.md`.
- Local development server is running and ready to use.
